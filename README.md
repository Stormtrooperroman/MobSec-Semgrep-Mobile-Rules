# MobSec Semgrep Mobile Rules

A collection of **Semgrep rules for mobile application security analysis**, used by the [MobSec — Mobile Security Testing Platform](https://github.com/Stormtrooperroman/MobSec) as part of its Semgrep module.

The ruleset helps identify potential security issues in mobile application code during static analysis.

## Rule Sources

This ruleset is inspired by the [`semgrep-mobile-rules`](https://github.com/Sib-Coder/semgrep-mobile-rules) project and incorporates rules and ideas from several mobile security resources, including:

- [OWASP MASTG](https://github.com/OWASP/MASTG) — the OWASP Mobile Application Security Testing Guide and its associated resources.
- [Minded Security — Android Security Rules](https://github.com/mindedsecurity/semgrep-rules-android-security) — Semgrep rules focused on Android application security.
- Other mobile application security research and rule collections.
